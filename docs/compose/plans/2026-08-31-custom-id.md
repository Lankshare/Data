# 自定义 ID 改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use SKILL:subagent-dev (recommended) or SKILL:execute-plan to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将数据文件从自增数字 ID 改为用户自定义 ID（仅允许小写字母、数字和连字符），并重命名所有现有文件为对应 github username。

**Architecture:** 文件名即 ID，create-link 脚本从 issue 表单读取用户填写的自定义 ID 并校验格式，update-link 脚本同样接受自定义 ID 格式。现有 21 个数据文件全部重命名。

**Tech Stack:** Node.js, GitHub Actions

### Task 4: 修改 create-link.js 脚本，支持自定义 ID

**Files:**
- Modify: `.github/scripts/create-link.js`

- [ ] **Step 1: 在 parseIssueBody 中添加 link_id 解析**

在 `parseIssueBody` 函数的 `fields` 对象中添加 `link_id: null`：

```javascript
  const fields = {
    link_id: null,
    title: null,
    name: null,
    desc: null,
    link: null,
    avatar: null,
    rss: null,
  };
```

在 `parseIssueBody` 函数中添加 link_id 的正则：

```javascript
  const idRegex = /###\s*Link ID\s*\n+([^\n]+)/i;
```

在匹配部分添加：

```javascript
  const idMatch = body.match(idRegex);
```

在赋值部分添加：

```javascript
  fields.link_id = cleanField(idMatch && idMatch[1]);
```

- [ ] **Step 2: 添加 ID 格式校验函数**

在 `processAvatar` 函数之后添加：

```javascript
// Validate custom ID format: only lowercase letters, numbers, and hyphens
function isValidId(id) {
  return /^[a-z0-9]([a-z0-9-]*[a-z0-9])?$/.test(id);
}
```

- [ ] **Step 3: 修改 main 函数，使用自定义 ID**

将 `main` 函数中获取 nextId 的逻辑替换为使用自定义 ID：

删除：
```javascript
    const nextId = getNextId(DATA_DIR);
    const newFilePath = path.join(DATA_DIR, `${nextId}.yaml`);
```

替换为：
```javascript
    if (!fields.link_id) {
      throw new Error("Required field missing: link_id");
    }

    if (!isValidId(fields.link_id)) {
      throw new Error(
        `Invalid Link ID: "${fields.link_id}". Only lowercase letters, numbers, and hyphens are allowed.`
      );
    }

    const newFilePath = path.join(DATA_DIR, `${fields.link_id}.yaml`);

    if (fs.existsSync(newFilePath)) {
      throw new Error(`Link ID "${fields.link_id}" already exists. Please choose a different one.`);
    }
```

- [ ] **Step 4: 更新输出信息**

将 `setOutput` 调用中的 `nextId` 改为 `fields.link_id`：

```javascript
    setOutput("outcome", "success");
    setOutput("message", `Successfully added link with ID ${fields.link_id}.`);
    setOutput("id", fields.link_id);
```

- [ ] **Step 5: 删除 getNextId 函数**

删除整个 `getNextId` 函数（不再需要）。

- [ ] **Step 6: Commit**

```bash
git add .github/scripts/create-link.js
git commit -m "feat: support custom ID in create-link script with validation"
```
